**BP-01 — high severity · high confidence — Movable action controls the release toolchain**

Location: [.github/workflows/build.yml:139](/Users/timmy/work/gam-review/audit/src/.github/workflows/build.yml:139)

Exact snippet:

```yaml
uses: jay0lee/python-openssl-latest@v1
```

This external action supplies Python and OpenSSL for release builds. Unlike most actions here, it uses a movable tag instead of a commit SHA. A changed or compromised tag can replace the interpreter, crypto implementation, or build output. Downstream GAM signing and attestations would then authenticate artifacts produced by that altered toolchain.

The supplied history records this build logic moving into the external repository in commit `efa65de7`.

To confirm: independently review the action’s resolved commit, its downloads and verification procedures, repository controls, and historical `v1` tag movements. Pin the reviewed commit.
