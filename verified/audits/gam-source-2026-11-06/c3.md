Locations: [src/gam/atom/http.py:250](/Users/timmy/work/gam-review/audit/src/src/gam/atom/http.py:250), [src/gam/atom/http_core.py:567](/Users/timmy/work/gam-review/audit/src/src/gam/atom/http_core.py:567).

`SSLContext(PROTOCOL_TLS)` does not enable certificate validation or hostname checking. These branches set neither, and load no trust roots. Supplying `server_hostname` supplies SNI; it does not enable verification.

**To confirm:** inspect those source diffs and, in a separately authorized isolated test, verify that the GData proxy path accepts an untrusted certificate while `no_verify_ssl=false`.
