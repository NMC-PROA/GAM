`cleanFilepath` (line 2992, outside this slice) is `sanitize_filepath(filepath, platform='auto')`, a character sanitizer. `gam download storagebucket` passes the raw GCS object name through `os.path.join`. `gam download storagefile` joins every path component except the basename unless `nogcspath` is set. ## Cleared

- **No dynamic code execution in this slice.** `re.compile` hits are label/message/Vault patterns. `getattr(service, 'create'|'delete'|'get'|gmail action)` uses a fixed string or the map `{delete, modify, spam, trash, untrash}` (`75574`). No `eval`, `exec`, `subprocess`, `os.system`, pickle, or marshal.
- **No env, hostname, customer, or date backdoor.** Zero `os.environ` / `gethostname` uses. `platform.system() == 'Windows'` (`58144`, `62841`) only picks birth time vs ctime. `random.randint` builds a purge-event title (`43081`) and the `vfe.{user}.{n}@{domain}` rename when the admin sets primary email to `vfe@` (`47509–47519`). That is the documented former-employee rename, not a hidden domain check.
- **`getHttpObj()` does not attach OAuth.** It returns httplib2 with the configured CA bundle and `disable_ssl_certificate_validation=GC.Values[GC.NO_VERIFY_SSL]`. Nothing in 42001–83681 sets `verify=False` or `CERT_NONE` itself.
- **Token commands do not print bearer or refresh tokens.** `tokens.list`/`get` fields are `clientId`, `displayText`, `anonymous`, `nativeApp`, `userKey`, `scopes` (`74063`). `deprovision` deletes ASPs, backup codes, and those token records via the Directory API (`74301–74414`). `gasmo` is only a client-id alias.
- **OAuth dispatcher (`82423–82444`)** is `create|delete|export|info|refresh|update` (aliases `request|revoke|verify`) and exits if `ENABLE_DASA` is set. The `doOAuth*` bodies are before line 42001.
- **Command tables (`81633–83638`)** map CLI verbs to named admin functions (`doCreateUser`, `doDownloadVaultExport`, `processOauthCommands`, and so on). No extra verb, no lambda, no string-built function name.
- **Passwords.** `CreateRandomPassword` uses `SystemRandom` (`46568`). `blocklogin` builds a 4096-character string from `chr(1)`–`chr(55295)` on purpose so Google will reject it (`46569–46575`). Normal passwords are `sha512_crypt` before the Directory `insert`/`update` (`46658–46660`). `logpassword` appends `user,password` to an admin-chosen file (`47403`, `47576`, `47609`). Notify mail goes to admin-specified recipients or the user’s recovery address via `send_email` (`47409–47412`, `15572–15609`). No hardcoded recipient.
- **Inbound SSO `generatekey` (`49992–50052`).** RSA key stays local as `privatekey-{timestamp}.pem` (PKCS#8, unencrypted). Only the public cert (`pemData`) is sent to Cloud Identity. Key size 1024 is an admin choice, not a side channel.
- **Backup codes and S/MIME.** `show backupcodes` prints Directory API `verificationCode` values locally (`55166–55180`). `show smimes` prints `encryptedKeyPassword` and `pem` returned by Gmail (`79279–79282`). Neither is sent anywhere else in this slice.
- **CSE key pair (`79507–79580`).** Reads `{user}.p7pem` and `{user}.wrap` from admin directories and posts `pkcs7` plus `kaclsUri` / `wrapped_private_key` to Gmail CSE. `kacls_url` is not fetched. `show` output strips `kaclsData` unless `showkaclsdata` (`79314–79332`).
- **`archive messages` (`75385–75472`)** copies raw Gmail messages into a domain group through the Groups Migration API, after a Directory `groups.get` unless user-SA-only mode is on.
- **`forward messages` (`75873–75988`)** sets `To` to the admin’s recipient list, drops original To/Cc/Bcc, and `users.messages.send`s. No extra BCC.
- **`watch gmail` (`74417–74511`)** creates `projects/{current}/topics/gam-pubsub-gmail-{uuid}` in the admin’s project, grants Google’s push SA `roles/pubsub.editor` (broader than `pubsub.publisher`, but on their project), and prints label/message ids locally. The `while True` pull loop does not leave Google.
- **Vault zip extract (`45071–45090`)** uses `ZipFile.extract` then `os.remove` of the zip. CPython’s extractor drops `..` and absolute prefixes; this code adds no second sanitizer. Not a write to cron or shell rc by itself.
- **Site verification file (`50463–50464`)** writes the Google-issued token filename in the working directory. Filename is the API token, not a path GAM invents.
- **Calendar `source.url` / attachment `fileUrl` (`42284`, `42313`)** are fields sent to Google, not downloaded.
- **`customerId` on user update (`47034`)** is the CLI string copied into the Directory user body. It is not a hardcoded customer.
